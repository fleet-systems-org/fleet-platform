# Typography

One typeface, IBM Plex Sans, bundled with the package from `@fontsource/ibm-plex-sans` (SIL Open Font License), weights 400 and 600. It is not loaded from an external CDN.

## Roles

Use a role, not a size. Four sizes exist: 12, 14, 16 and 20 px.

## Rules

| Rule | Source |
|---|---|
| IBM Plex Sans, not Inter, Arial or the system font stack. | N2a, R14.1, audit finding 3 |
| Four sizes only: label 12/16, body 14/20, heading 16/24, page 20/28. No size outside the scale. | R14.1, N2a, audit finding 6 |
| Body text is 14 px; the screen is dense but the type is not small. | Q3-1 |
| Amounts, kilometres and times use `tabular-nums` and are right-aligned in columns. | P8, R07.1, R15.1 |
| Table headers are semibold. | P7 (proposal), R14.1 |
| Running text is at most about 65 characters per line (`max-w-measure`). | Audit finding 15 |
| A label sits above its value in `text-label text-muted`. | R07.1 |
| Code samples in this documentation use the system monospace font; the product shows no code. | Proposal |
