# Place picker

`import { PlacePicker } from "@fleet-platform/ui/components/places/place-picker"`

## 1. Purpose

Lets the dispatcher find a route endpoint by typing an address or a town and choose exactly one result. It always says whether the choice is an exact address or only a town (P04, PLACE-3), and it never merges spellings or same-named towns by itself (PLACE-2).

## 2. When to use

- Loading and unloading places of a trip (E01 trip entry, s09–s10).
- The vehicle's starting point (s08).

## 3. When not to use

| Situation | Use instead | Why |
|---|---|---|
| Showing a place | Text with the place's name and kind | Entry and display are separate |
| A short fixed list (country, currency) | Select | Known values are chosen, not searched |
| Typing an address or coordinates by hand | Nothing: choose a map result, a saved place or a town | A place is added only from a map result (L09) |

## 4. Anatomy

Label, hint and error from `Field`; the search box; the list under it with each result's name, kind ("Zapisane miejsce", "Adres", "Tylko miasto"), address or region and country, a "Do potwierdzenia" badge for same-named towns and the typed spelling when it differs; a status line in the list; under the box, the chosen result's kind and address, and "Dodaj miejsce" while a map address is chosen and the page allows it (L09).

## 5. Variants

One look. The page decides the content: saved places while nothing is typed, then the results of the last search, saved places first.

## 7. Behaviour and accessibility

- WAI-ARIA combobox with a list: typing calls `onQueryChange`; the page searches (saved places, then the map provider) and passes `options` and `status`. Down and Up move through the results and wrap; Enter chooses; Escape closes the list; leaving the box closes it.
- Choosing calls `onSelect(option)`; typing again clears the choice and calls `onSelect(null)`, so a stale endpoint is never kept.
- The search status ("Szukam…", the number of results, not found, unavailable) is announced through a status region; the chosen result's kind and address are part of the box's description.
- The box is named by the `Field` label; hint and error are in `aria-describedby`; `aria-invalid` and `required` come from `Field`. "Dodaj miejsce" is a button under the box, shown only while a map address is chosen, reachable with Tab.

## 8. Content

- A town without an address says so: "Tylko miasto · Region Północ · PL".
- A country nobody confirmed is not guessed: "kraj niepotwierdzony".
- Messages say what to do: "Nie znaleziono adresu. Sprawdź pisownię albo wybierz zapisane miejsce lub samo miasto.", "Wyszukiwanie adresów jest teraz niedostępne. Wybierz zapisane miejsce albo samo miasto."

## 9. Responsive

The list takes the width of the box; result lines wrap; at 320 px nothing scrolls sideways.

## 10. API

`PlacePicker`: `options` (`PlaceOption[]`: `id`, `kind: "place" | "address" | "town"`, `name`, `detail?`, `country?`, `needsConfirmation?`, `typedAs?`), `status` (`idle`, `searching`, `results`, `notFound`, `unavailable`), `labels`, `defaultValue`, `onQueryChange(query)`, `onSelect(option | null)`, `onAddPlace`, `disabled`. Searching, debouncing and saving aliases stay with the page.

## 11. Code

```tsx
const [status, setStatus] = useState<PlaceSearchStatus>("idle");
const [options, setOptions] = useState<PlaceOption[]>(savedPlaces);

<Field label="Miejsce załadunku" hint="Adres albo miasto" error={error} required>
  <PlacePicker status={status} options={options} labels={placePickerLabels}
    onQueryChange={query => search(query)} // sets status and options from apiCall
    onSelect={option => setLoadingPlaceId(option?.id ?? null)}
    onAddPlace={canWritePlaces ? option => savePlace(option) : undefined} /> // one action, map addresses only (L09)
</Field>
```

## 12. Do and don't

| Do | Don't |
|---|---|
| Show both "Miasto D" results with their regions. | Choose the first "Miasto D". |
| Show "wpisano: Miejsce-B" and let a person choose. | Merge "Miejsce-B" into "Miejsce B" silently. |
| Keep saved places selectable when the map provider fails. | Block the whole field because geocoding is down. |

## 13. Related

Built on: `Field`, `Badge`, `Button` (text), the input styles of Input. Used in: trip entry (loading, unloading), vehicle start. Alias confirmation (`towns.confirmAlias`) and adding a place are separate flows.
